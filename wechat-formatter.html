公众号快速排版

Markdown 或现成 HTML → 实时预览 → 一键复制，直接粘进公众号编辑器
输入 Markdown 原文可拖入 .html / .md / .txt 文件
松开鼠标即可导入文件
0 字符 · 0 行内容自动保存在本机浏览器
预览 手机端效果（约 375px）
—复制后到公众号编辑器 Ctrl+V 粘贴
Markdown 模式：# 标题 ## 小节 ### 小标题 **加粗** > 引用 - 列表 1. 步骤 - [ ] 清单 | 表格 | ![图注](图片地址) --- 分隔线。
HTML 原格式模式：直接把现成的 HTML 粘贴进来（或点「导入 HTML 文件」）。工具会解析 <style> 里的样式并转成内联样式——配色、字号、表格、图片全部原样保留，公众号编辑器可直接识别。适合处理已经排好版的 HTML 成品。
拖入文件：把 .html / .md / .txt 文件直接拖到左侧输入区即可导入（按扩展名自动切换模式）；拖入图片会插入 Markdown 图片语法；拖入纯文本会追加到末尾。
关于图片：工具已把图片规范化为公众号兼容写法并加 !important（width:100% !important; max-width:100% !important; height:auto !important），粘贴后自动撑满自适应，无需再点编辑器的「自适应」按钮；同时去掉 figure、圆角、object-fit 避免被裁切。若个别图片仍显示固定宽度，点编辑器里该图的「自适应」即可。公众号会把 base64 图片重新上传编码，清晰度可能略降（平台行为），要求画质可粘贴后手动替换原图。
